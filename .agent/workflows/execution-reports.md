## Execution Report Naming Convention

When completing a directive (e.g., `CLAUDE_DIRECTIVE_6.md`), **always** save the execution report as `EXECUTION_REPORT_N.md` where `N` matches the directive number.

- Directive 1 → `EXECUTION_REPORT_1.md`
- Directive 2 → `EXECUTION_REPORT_2.md`
- Directive 6 → `EXECUTION_REPORT_6.md`
- etc.

**Do NOT** save as the generic `EXECUTION_REPORT.md`. The user expects numbered reports every time without having to ask.
