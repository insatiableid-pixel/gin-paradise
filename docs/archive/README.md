# Repository Archive

This directory contains historical AI work logs and standalone research code that
is not part of the Gin Paradise web application. The production app, its tests,
and its operational documentation live in `gin-galaxy/`.

- `ai-worklogs/` preserves old directive and execution-report records without
  crowding the repository root.
- `research/` preserves the Python/Rust oracle experiments and support tools.

Archived code is not installed, built, or executed by the Gin Paradise CI
pipeline. Generated artifacts (including Rust `target/` output and browser crash
dumps) must remain untracked.
